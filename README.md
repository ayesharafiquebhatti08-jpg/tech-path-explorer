# tech-path-explorer

**AI-powered technology career exploration**

Tech Path Explorer is a beginner-friendly tool designed to help students explore different technology career paths based on their interests, coding preferences, future goals, and background.

Instead of telling users what career they should choose, Tech Path Explorer helps them understand different fields and try small experiments before deciding what they want to explore further.

## Technology Fields

* Artificial Intelligence / Machine Learning
* Cybersecurity
* Data Science
* Software Engineering
* Information Technology
* Cloud / DevOps
* Robotics
* UI/UX and Product Design

## How It Works

1. The user answers five questions about themselves.
2. The AI analyzes their answers.
3. The tool suggests 3–4 technology paths worth exploring.
4. Each path explains the field, relevant skills, possible jobs, internship opportunities, and beginner-level work.
5. The user receives a tiny experiment to try the field.
6. The user reflects on whether they enjoyed the experience.

## Goal

Help beginners move from:

**"I don't know which technology field is right for me."**

to:

**"I understand my options, and I know what I can try next."**
